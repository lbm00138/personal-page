        這是我在暑假剛學 HTML 時利用 HTML 與 Python 來完成的終極井字遊戲。一開始我先用 Python 寫好後端，接著利用 HTML 完成前端，然後我用 AI 幫忙整合前後兩端並把完成的專案上傳到 GitHub 上。
